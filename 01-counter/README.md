# 🔢 Counter App

A modern and minimal counter application built with React.js and JavaScript.

This project is the first application in my React.js project journey, focusing on React fundamentals, state management, event handling, and component-based development.

## ✨ Features

- Increment counter value.
- Decrement counter value.
- Reset counter to zero.
- Prevent negative values.
- Interactive buttons.
- Modern dark UI.
- Responsive design.

## 🛠️ Built With

- React.js
- JavaScript (ES6+)
- CSS3
- Vite

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/Easy-QuantumDev/projects-with-react-js.git
```

Navigate to the project directory:

```bash
cd projects-with-react-js/01-counter
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
